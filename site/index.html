How it works

Data is downloaded with yfinance, validated and stored in two tables. No metric is stored: each one is a SQL query run on demand.

  • Ingestion

    Incremental daily updates. The last stored days are re-downloaded and compared, so a dividend that changes past adjusted prices triggers a full reload.

  • Storage

    SQLite with strict types, a composite (asset_id, date) key and CHECK constraints that reject inconsistent prices.

  • Analytics

    LAG, FIRST_VALUE and rolling window sums. SQLite has no STDDEV or CORR, so both are written out and tested against pandas.
